# v1.1.2 — Catalog Update: DeepSeek V4 Flash 0731 Removal

This patch update synchronizes the extension's model catalog with upstream NVIDIA NIM changes.

## What changed for you

* **Model catalog synchronization.** Removed DeepSeek V4 Flash 0731 from the extension catalog and settings menus following its removal from NVIDIA NIM endpoints. This prevents confusion when selecting models in settings and ensures the model picker accurately reflects available services.

## Install / Update

Install from the Visual Studio Marketplace, update through the Extensions view in VS Code, or install from the `nvidia-nim-agent-1.1.2.vsix` package.
