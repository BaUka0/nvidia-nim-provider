# v0.4.9

## What's New

- **Smaller Marketplace package.** Removed development-only `.mimocode` metadata from the VSIX. The package is now under 600 KB instead of roughly 12 MB.
- **Version bump.** Published as `0.4.9` so VS Code Marketplace can recognize it as an update to `0.4.8`.

## Install

Download the `nvidia-nim-agent-0.4.9.vsix` file and install it from the VS Code Extensions view using **Install from VSIX...**
