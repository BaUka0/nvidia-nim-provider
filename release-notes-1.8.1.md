# v1.8.1 — Nemotron 3 Super Removed

NVIDIA retired Nemotron 3 Super on October 19, 2026. It still appears in NVIDIA's model list, but every request to it now fails, so this release removes it from the model picker.

## What changed for you

* **Nemotron 3 Super is gone from the model picker.** Pick another model for your chats. Nemotron 3.5 Super VL, NVIDIA's newer Super model with image input, stays in the list.
* **Backup and summarization settings.** If Nemotron 3 Super was your backup or summarization model, the extension uses the default model instead. You can choose a different one in the VS Code Settings UI or `settings.json`.

GLM 5.3 is next: NVIDIA retires it on October 27, 2026, and the model picker already shows its countdown.

## Install / Update

Install from the Visual Studio Marketplace, update through the Extensions view in VS Code, or install from the `nvidia-nim-agent-1.8.1.vsix` package.
