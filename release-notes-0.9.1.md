# v0.9.1 — DeepSeek V4 Pro 0813 Model Support

This update adds support for the DeepSeek V4 Pro 0813 model to the curated NVIDIA NIM catalog.

## DeepSeek V4 Pro 0813

* **High-Capacity Coding & Reasoning Model:** Added `deepseek-ai/deepseek-v4-pro-0813`, offering deep reasoning capabilities and strong code generation performance.
* **Context & Output Limits:** Features a 1,048,576-token context window and up to 131,072 max output tokens for extensive codebase analysis and generation tasks.
* **Native Tool Calling:** Fully integrated with native tool calling and agent workflows in Copilot Chat.
* **Reasoning Modes:** Supports selectable reasoning effort modes (`none`, `high`, `max`) with dedicated thinking stream isolation.
* **Settings & Availability:** Available directly in the VS Code model picker, with full support across failover chains and history summarization settings.

## Install / Update

Install from the Visual Studio Marketplace, update directly through the Extensions view in VS Code, or install from the `nvidia-nim-agent-0.9.1.vsix` package.
