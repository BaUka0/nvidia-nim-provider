# v1.2.0 — DeepSeek V4.1 Flash & Intelligence Index v4.3.2

This minor release adds DeepSeek V4.1 Flash to the curated model catalog and updates benchmark ratings across all supported models.

## What changed for you

* **DeepSeek V4.1 Flash.** Added DeepSeek V4.1 Flash to the curated model catalog. The model features a 1-million-token context window, native multimodal image analysis (Vision), tool calling, and adjustable reasoning effort levels (`None`, `Low`, `High`, `Max`) directly in the Copilot Chat model picker.
* **Artificial Analysis Intelligence Index v4.3.2.** Updated model capability ratings across the catalog to the latest v4.3.2 benchmark release, reflecting recent methodology updates in agentic workflows, coding evaluations, and multimodal tasks.

## Install / Update

Install from the Visual Studio Marketplace, update through the Extensions view in VS Code, or install from the `nvidia-nim-agent-1.2.0.vsix` package.
