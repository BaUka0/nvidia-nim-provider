# v1.10.0 — Mistral Large 4

This release adds Mistral Large 4 to the model picker.

## New Model

* **Mistral Large 4.** A large multimodal model from Mistral AI for agentic coding, tool use, and document and image analysis, with a 1M-token context window, up to 262,144 output tokens, tool calling, and image input. It always reasons and shows its reasoning in the Thinking block; Reasoning Mode offers `Low`, `Medium`, and `High`. It scores 26 on the Artificial Analysis Intelligence Index v5 and can also be selected as your backup, vision backup, or summarization model in the VS Code Settings UI or `settings.json`.

## Documentation

* **Updated model scores.** The model tables in the README and model guide now use the Artificial Analysis Intelligence Index v5. Scores on this version are lower across the board than on the previous one, so they are not comparable with the numbers shown before. GLM 5.3 Flash and Nemotron 3.5 Lightning have not been scored on v5 yet.

## Install / Update

Install from the Visual Studio Marketplace, update through the Extensions view in VS Code, or install from the `nvidia-nim-agent-1.10.0.vsix` package.
